# forkbid.com

Static site for the vanilla-rtb project, served by GitHub Pages.

The content is a static capture of the former WordPress site, taken on
2026-10-26. The contact form became a mailto link; comments are closed.

To change a page, edit its `index.html` and push to `main`. No build step.
Do not add a `CNAME` file until the forkbid.com DNS points at GitHub Pages.
